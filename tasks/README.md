# Очередь задач

Создавайте каждую задачу отдельным файлом, используя templates/task.md.

## Правила
- ID уникален: TASK-YYYYMMDD-NNN.
- Одна задача — один исследовательский вопрос.
- Статусы: ready, in_progress, blocked, review, done, cancelled.
- Не изменяйте завершённые задачи задним числом: создавайте новую задачу или исправление со ссылкой на исходную.
- Не помещайте API-ключи, пароли, личные данные и защищённые книги в задачи.
- Для ручного запуска скопируйте содержимое задачи в чат библиотекаря.
