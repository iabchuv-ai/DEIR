# Цель
Подготовить начальную карту доступных источников по ДЭИР и определить, какие утверждения можно проверять по открытым материалам.

# Исследовательский вопрос
Какие первичные, официальные, независимые и критические источники доступны для изучения ДЭИР, и какие ограничения есть у каждого типа источников?

# Границы поиска
- Ищи открытые и законно доступные материалы.
- Разделяй источники самого движения/авторов, независимые исследования, критические материалы и общие упоминания.
- Не делай вывод, что утверждение истинно только потому, что оно опубликовано официальным источником.
- Не загружай защищённые книги целиком в репозиторий.

# Что включать
- Название, автор/организация, URL, дата (если подтверждена), тип источника.
- Какие вопросы источник способен поддержать, а какие — нет.
- Прямые независимые проверки существенных заявлений, если найдутся.

# Что исключать
- Непроверяемые ссылки, вымышленные публикации и неподтверждённые цитаты.
- Большие фрагменты защищённых текстов и личные данные.

- [ ] Есть карта источников с проверяемыми URL

- [ ] Обозначены пробелы и ограничения
