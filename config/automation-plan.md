# План автоматизации ДЭИР

## Этап 1 — Репозиторий
- [x] Базовый README.
- [ ] Протокол ролей и сообщений.
- [ ] GitHub Actions для проверки структуры и шаблонов.

## Этап 2 — Безопасная интеграция
- Уточнить и проверить актуальную официальную документацию Z.ai/BigModel: API base URL, версию API, модель, управляемые агенты и формат инструментов.
- Хранить ключи только в GitHub Actions Secrets; не помещать их в файлы, логи или сообщения.
- Начать с ручного запуска и минимальных прав; сначала dry-run и тестовая база знаний.

## Этап 3 — Пайплайн материалов
1. Исследователь находит источники и готовит отчёт.
2. Рецензент проверяет релевантность, происхождение, дату и права использования.
3. Координатор принимает окончательное решение.
4. Только одобренные материалы передаются в базу знаний.
5. Ответы должны ссылаться на найденные фрагменты; при отсутствии подтверждения — честно сообщать об этом.

## Этап 4 — Автоматизация
- Добавить тесты на структуру, метаданные, секреты и обработку ошибок.
- Настроить ручной запуск GitHub Actions до включения расписания.
- Для периодических задач использовать lock/idempotency, ограниченные повторы с backoff для 429/5xx и журналирование без секретов.
- Добавлять один небольшой отчёт на heartbeat и эскалировать повторяющиеся блокировки.

## Критерии приёмки
- Нерелевантный материал отклоняется рецензентом.
- Релевантный материал сопровождается источником и обоснованием.
- Добавление в базу знаний выполняется только после одобрения координатора.
- Ответы цитируют материалы; при отсутствии подтверждения модель не выдумывает ответ.
- Логи не содержат API-ключей.

## Важно
Документы плана не запускают фоновые агенты. Реальное подключение Z.ai, расписание и база знаний требуют проверенной документации, настроенных секретов и тестового запуска.
