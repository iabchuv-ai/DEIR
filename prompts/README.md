# Запуск двух чатов без Z.ai API

## Чат 1: Библиотекарь
Откройте новый чат, подключите доступ к GitHub, если ваш интерфейс это поддерживает, и вставьте целиком файл:
prompts/PROMPT_LIBRARIAN.md

После вставки отправьте команду:
«Выполни стартовую процедуру. Проверь доступ к репозиторию и инструментам. Не начинай исследование, пока не сообщишь, какие файлы действительно прочитал и какие инструменты доступны».

## Чат 2: Учитель
Откройте отдельный чат, подключите доступ к GitHub, если доступно, и вставьте целиком файл:
prompts/PROMPT_TEACHER.md

После вставки отправьте команду:
«Выполни стартовую процедуру. Проверь доступ к репозиторию и инструментам. Не утверждай, что библиотекарь связан с тобой автоматически».

## Как передавать работу
- Если оба чата умеют читать/писать в один репозиторий, учитель создаёт задачу в tasks/, библиотекарь читает её и сохраняет отчёт в reports/, учитель проверяет и при необходимости сохраняет заметку в knowledge/.
- Если запись в GitHub доступна только одному чату или недоступна обоим, передавайте полные тексты файлов вручную через пользователя.
- Не считайте публичную ссылку на GitHub подключением с правом записи.
- Не публикуйте ключи и пароли. Z.ai API для этого режима не требуется.
- GitHub Actions проверяет структуру файлов; он не запускает ИИ-агентов и не делает автоматический веб-поиск.

## Рекомендуемые папки
- tasks/ — задания
- reports/ — исследовательские отчёты
- reviews/ — отзывы учителя
- knowledge/ — только принятые учебные заметки
- logs/ — журнал решений и блокировок
