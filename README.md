# ДЭИР — AI-ментор

Проект мультиагентного ИИ-ментора по ДЭИР с базой знаний, исследованием источников и проверкой материалов.

## Статус

Начальная структура проекта. Интеграция с Z.ai и автоматические агенты ещё не настроены.

## Принципы

- Ответы по возможности основываются на утверждённой базе знаний.
- Агент-исследователь находит источники, но не утверждает их самостоятельно.
- Агент-рецензент проверяет релевантность, происхождение и противоречия.
- Только координатор утверждает материалы для базы знаний.
- Секреты API хранятся в GitHub Actions Secrets и никогда не коммитятся.

## Структура

- `protocol/` — роли и протокол взаимодействия.
- `templates/` — шаблоны отчётов и рецензий.
- `config/` — план автоматизации.
- `.github/workflows/` — проверки репозитория.

## Безопасность и права на материалы

Добавляйте только материалы, которые разрешено использовать. Не коммитьте книги, персональные данные, ключи API или другие секреты.
